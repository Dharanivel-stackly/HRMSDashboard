# HRMS Dashboard

One Enterprise Cloud Platform — HRMS frontend built with React, Vite, TypeScript, Tailwind CSS, and shadcn/ui.

## Features

- Authentication (login, forgot password) with mock API support
- HRMS dashboard and employee management
- Full Attendance module UI (dashboard, daily attendance, corrections, shifts, holidays, overtime, reports)
- RBAC-ready navigation and permissions
- Stackly branding

## Getting Started

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and set `VITE_USE_MOCK_API=true` for demo mode.
